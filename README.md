# cards-market-bot
Телеграмм бот магазин для карточек товаров, которые может добавлять пользователь, есть меню администратора для множества функций, таких как,модерирование карточек, статистика и тд.

## Основные функции
Бот может добавлять карточки пользователя, которые можно покупать и продавать через инвойс в телеграмме. Также есть меню для администратора для просмотра заявок на вывод, статистики пользователей и их карт.
Просмотр карточек, заявок и где требуется пагинация, реализованы Inline кнопки для перелистования страниц с данными.

**Функции модерирования карт:**
Добавить
Удалить
Изменить (имя, описание)

Данный бот реализован в модульной архитектуре.

## Запуск

```bash
docker compose up -d --build
```
